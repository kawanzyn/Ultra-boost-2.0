# Changelog

## v2.0.0-alpha.1 — Basic

- Preserved the reversible client-side visual engine from the v0.4.0 baseline.
- Added Ultra, Balanced and Light visual profiles.
- Added conservative classification for protected gameplay objects and environmental geometry.
- Added reversible material, texture, lighting and terrain adjustments.
- Added optional local environmental collision changes.
- Added batched restoration and bounded scanning to reduce large one-frame workloads.
- Added FPS estimation, touch/mouse dragging, minimize and restore controls.

This changelog covers the public Basic distribution only.
